# გზა — ლოჯისტიკური და ტრანსპორტირების პლატფორმა

„გზა“ არის React და TypeScript-ზე შექმნილი ვებაპლიკაცია, რომელიც მომხმარებლებს მარშრუტების მოძიებაში, რეისების მართვასა და ადგილების დაჯავშნაში ეხმარება. პროექტი აერთიანებს მარტივ ინტერფეისს, მომხმარებლის ავტორიზაციას, მარშრუტების მართვის შესაძლებლობებს და დაჯავშნის პროცესს.

## ძირითადი შესაძლებლობები

- მარშრუტების დათვალიერება, ძიება და ფილტრაცია.
- მარშრუტის დამატება, რედაქტირება და წაშლა შესაბამისი უფლებების მიხედვით.
- მომხმარებლის რეგისტრაცია და ავტორიზაცია.
- მომხმარებლის როლები: მგზავრი, მძღოლი, კომპანია და ადმინისტრატორი.
- მარშრუტის თავისუფალი ადგილების რაოდენობის კონტროლი.
- მარშრუტზე ადგილის დაჯავშნა და ჯავშნების ისტორიის ნახვა.
- საფულის ბალანსის მართვა, შევსება და ტრანზაქციების ისტორია.
- ჯავშნის თანხის ჩამოჭრისა და მარშრუტის მფლობელის შემოსავლის აღრიცხვა.
- ინტერაქტიული რუკა Leaflet-ისა და OpenStreetMap-ის გამოყენებით.
- მომხმარებლის როლების მიხედვით მართვის პანელისა და სტატისტიკის ჩვენება.
- ადაპტირებული დიზაინი დესკტოპის, ტაბლეტისა და მობილურისთვის.
- ფორმების ვალიდაცია და შეცდომების გასაგები შეტყობინებები.
- API-სთან დაკავშირების პრობლემისას ადგილობრივი ქეშის ან დემო მონაცემების ჩვენება.
- შეცდომების მართვა Error Boundary-ის საშუალებით.
- მარშრუტების ძიების ოპტიმიზაცია და გვერდების დინამიკური ჩატვირთვა.

## პროექტის არქიტექტურა

პროექტი დაყოფილია ფრონტენდისა და ბექენდის ნაწილებად.

- **Frontend** პასუხისმგებელია ინტერფეისზე, გვერდებზე, ფორმებზე, მარშრუტების ძიებასა და მომხმარებლის ინტერაქციაზე.
- **Backend** ამუშავებს API მოთხოვნებს, მომხმარებლის ავტორიზაციას, მარშრუტების მართვასა და დაჯავშნის ბიზნეს-ლოგიკას.
- **SQLite** ინახავს მომხმარებლების, მარშრუტების, ჯავშნებისა და ტრანზაქციების მონაცემებს.

მარშრუტების მართვისას მოწმდება მომხმარებლის როლი და მარშრუტის მფლობელობა. დაჯავშნისას სერვერი ამოწმებს თავისუფალი ადგილების რაოდენობას, რათა არ მოხდეს ხელმისაწვდომზე მეტი ადგილის დაჯავშნა.
